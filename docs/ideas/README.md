# Ideas

This folder is a low-cost place to explore possible Happy Path features, experiences, and extensions. An idea is not part of the product scope until it is promoted into the [PRD](../PRD.md).

## Add an idea

1. Copy [TEMPLATE.md](TEMPLATE.md) to a clearly named Markdown file such as `scenic-paths.md`.
2. Explain the user value before the implementation.
3. Note important data, trust, or feasibility questions.
4. Give the idea one status: `inbox`, `exploring`, `prd-candidate`, `parked`, or `rejected`.
5. Link it below so this page stays useful as the idea index.
