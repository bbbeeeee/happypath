# Ideas

This folder is a low-cost place to explore possible Happy Path features, experiences, and extensions. An idea is not committed product scope until it is promoted into the [PRD](../PRD.md).

## Statuses

- `inbox` — captured but not evaluated
- `exploring` — active research or design work
- `prd-candidate` — supported enough to consider for scope
- `promoted` — incorporated into a canonical document
- `parked` — useful later but not active
- `rejected` — intentionally excluded, with rationale

## Add an idea

1. Copy [TEMPLATE.md](TEMPLATE.md) to a clearly named Markdown file.
2. Explain user value before implementation.
3. Record data, trust, feasibility, and product-boundary questions.
4. Assign one status.
5. Link it below.
