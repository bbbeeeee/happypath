# Happy Path docs

This folder is the shared product workspace for Happy Path.

## Documents

- [PRD](PRD.md) — the source of truth for the product we decide to build
- [Data and inference specification](data-and-inference.md) — public sources, evidence rules, and the boundary between inference and routing
- [Ideas](ideas/README.md) — possibilities worth exploring without committing them to the PRD
- [Tasks](../tasks/README.md) — discrete work that collaborators can claim in parallel

## Working agreement

1. Put confirmed product direction in the PRD.
2. Put uncommitted possibilities in `ideas/`, one idea per file.
3. Put actionable work in `tasks/`, one task per file.
4. Mark uncertainty explicitly instead of presenting assumptions as decisions.
5. Keep engineering choices open until the product scope calls for them.
